# T&E interview prep

Use before each T&E Visibility interview. Ask for the interviewee's role and company size if they weren't given.

## Steps
1. Read `discovery/pain-points.md`, `prototype/interview-scope.md` and the latest `discovery/interview-guide-*.md`.
2. List the pain points still marked hypothesis, weakest evidence first. These get the most interview time.
3. Tailor the guide to this interviewee:
   - Keep the structure: warm-up, today's workflow, pain probes, prototype tasks, wrap-up.
   - Reword the probes for their role and company size.
   - Drop probes for pain points already validated three or more times, and keep one confirmation question.
4. Check the prototype checklist in `interview-scope.md`, and name anything not ticked.
5. Create `discovery/interview-guide-NN.md` (next number) for this interviewee, and a notes file from `discovery/interview-notes-template.md` named `discovery/notes-YYYY-MM-DD-<code>.md`.
6. Reply with: the 3 things to learn from this interview, the screens to show in order, and any prototype gaps.

## Rules
- No leading questions. Ask about the last real time something happened.
- Never put the interviewee's personal data beyond role, company type and a code name into the repo.
